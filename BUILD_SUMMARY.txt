GETTING STARTED
================================================================================

1. Install Dependencies:
   npm install
   cd backend && npm install && cd ..
   cd frontend && npm install --legacy-peer-deps && cd ..

2. Start Development:
   npm start
   
   Or separately:
   npm run dev:backend    # Terminal 1
   npm run dev:frontend   # Terminal 2

3. Open in Browser:
   Frontend: http://localhost:3000
   Backend: http://localhost:5000/api/events

4. Build for Production:
   npm run build
   Output: frontend/dist/

CUSTOMIZATION GUIDE
================================================================================

Change Colors:
  → Edit frontend/tailwind.config.js (colors section)

Update Events:
  → Edit backend/server.js (eventsData array, line ~8)

Modify 3D Objects:
  → Edit frontend/src/components/Hero3D.jsx

Add New Pages:
  → Create file in frontend/src/pages/
  → Add route in App.jsx
  → Update Navigation.jsx

Add API Endpoints:
  → Edit backend/server.js
